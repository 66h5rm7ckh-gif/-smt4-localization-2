# SMT IV Russian Localization

This directory contains the translation layer for the extracted Shin Megami Tensei IV English corpus.

## Rules
- Keep file path and numeric entry ID unchanged.
- Keep all control codes exactly intact unless a dedicated validator permits a safe transformation.
- Keep `[END]` markers unchanged.
- `en` is the immutable English source.
- `ru` contains the Russian translation.
- Translation status is tracked per entry.
